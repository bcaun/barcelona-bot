## Что умеет бот сейчас

**Для пользователей**
- `/start` — приветствие и меню: 🧮 Калькулятор, 🔎 Проверить объект, 🎮 Игра
  (пока «скоро»), 📢 Наш канал, ✉️ Связаться, 🌐 Язык.
- «🔎 Проверить объект» (или `/check`) — поиск в открытом кадастре Испании по кадастровому
  номеру (RC, 20 или 14 символов), по адресу (улица из справочника Catastro → номер → квартира)
  или по геоточке. Показывает адрес, назначение, площадь, год постройки, долю, ссылки на
  Sede Catastro и флаги (напряжённый рынок, туристические лицензии, ITE для старых зданий).
  Кнопки: «📄 Заказать nota simple» (заявка `nota_simple`), «🧮 Рассчитать расходы»,
  «📩 Консультация» (заявка `object_check`).
- «🧮 Рассчитать стоимость покупки» (или `/calc`) — пошаговый расчёт налога на покупку
  (ITP по шкале / льгота 5% / крупный собственник / IVA + AJD), расходов на сделку, ежегодных
  платежей (IBI, IRNR нерезидента) и доходности аренды. Кнопка «📩 Подобрать объекты под
  этот бюджет» создаёт заявку `calc` со всеми параметрами расчёта.
- «✉️ Связаться» — согласие на обработку данных → телефон (кнопкой Telegram) или только
  username → заявка приходит в группу заявок.
- `/language` — сменить язык (русский / английский; по умолчанию — по языку Telegram).
- `/delete_me` — удалить все свои данные и заявки.

**Для администраторов** (ID из `ADMIN_IDS` в `.env`)
- `/stats` — пользователи за сегодня / 7 дней / всего, заявки по типам и источникам.
- `/leads_csv` — все заявки CSV-файлом (открывается в Excel: кодировка UTF-8, разделитель `;`).
- `/chatid` — показывает ID текущего чата (нужен для `ADMIN_CHAT_ID`).

## Источники трафика (deep links)

Чтобы видеть, какой пост канала привёл заявку, ставьте в посты ссылку на бота с меткой:

```
https://t.me/ИМЯ_БОТА?start=post_123
```

Метка — латиница, цифры, `_` и `-`, до 64 символов. Примеры: `post_123`, `site`, `game`,
`insta_bio`. Метка сохраняется у пользователя (первая — навсегда, последняя — обновляется)
и у каждой его заявки. В `/stats` — раздел «По источникам», в CSV — колонка `source`.

## Настройки

**Свои значения пишите в файлы `config/*.local.yaml`**, а не в основные файлы. Например,
`config/settings.local.yaml` или `config/taxes.local.yaml`. В них достаточно указать только
то, что меняете, — остальное берётся из основного файла. Локальные файлы не хранятся в git,
поэтому `git pull` никогда не затрёт ваши правки и не будет конфликтовать.

Пример `config/taxes.local.yaml` — поменять ставку AJD и дату сверки:

```yaml
verified_at: "2026-12-01"
new_build:
  ajd: 0.02
```

| Файл | Что там | Как применить |
|---|---|---|
| `.env` | секреты: токен, ID админов, ID чата заявок, канал | `docker compose up -d --force-recreate bot` |
| `config/settings.yaml` | ссылка на канал, политика конфиденциальности, реквизиты, лимиты | `docker compose restart bot` |
| `config/taxes.yaml` | ставки налогов и сборов калькулятора | `docker compose restart bot` |
| `config/regulation.yaml` | зоны регулирования и тексты предупреждений | `docker compose restart bot` |
| `app/i18n/ru.yaml`, `en.yaml` | все тексты бота | `git pull && docker compose up -d --build` |

## Персональные данные (GDPR / LOPDGDD)

Бот хранит только: Telegram ID, username, язык, дату первого входа, метку источника и
список действий (нажатия кнопок и команды — **без текста переписки**). Заявка создаётся
только после нажатия «Согласен на обработку данных»; в ней — имя из Telegram, username,
телефон (если человек сам его отправил) и время согласия.

`/delete_me` удаляет пользователя, его действия и заявки из базы. Карточки этих заявок в
группе бот пытается удалить (Telegram позволяет это только в течение 48 часов) и в любом
случае присылает в группу уведомление с номерами удалённых заявок — если вы переносили их
в CRM или таблицы, удалите вручную.

**Что добавить в политику конфиденциальности** (черновик, сверьте с юристом):

> Telegram-бот @ИМЯ_БОТА обрабатывает ваш Telegram ID, имя пользователя, язык интерфейса
> и сведения о действиях в боте для работы сервиса и статистики. Имя и номер телефона
> обрабатываются только после вашего согласия и только для связи с вами по вашему запросу.
> Вы можете в любой момент удалить свои данные, отправив боту команду /delete_me, или
> обратиться к оператору данных: [реквизиты из legal.controller].

## Для разработчика

Python 3.12, aiogram 3, SQLAlchemy 2 + Alembic, SQLite (схема переносима на PostgreSQL).

```bash
uv venv -p 3.12 .venv && uv pip install -p .venv -e ".[dev]"
```

```bash
cp .env.example .env   # заполнить BOT_TOKEN и DATABASE_URL=sqlite+aiosqlite:///./data/bot.db
```

```bash
.venv/bin/alembic upgrade head && .venv/bin/python -m app.bot
```

Тесты и линтер:

```bash
.venv/bin/pytest && .venv/bin/ruff check . && .venv/bin/ruff format --check .
```

Интеграционные тесты с реальными внешними API (появятся в Фазе 2) запускаются отдельно:
`.venv/bin/pytest -m integration`.

Новая миграция после изменения моделей:

```bash
.venv/bin/alembic revision --autogenerate -m "describe change"
```
